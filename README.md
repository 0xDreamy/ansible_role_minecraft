### 🏠 [Homepage](https://github.com/0xDreamy/ansible_role_minecraft)

## Usage

You can use this role in your Ansible playbook like this :

```
- name: "Install minecraft"
  hosts: minecraft_server
  roles:
    - ansible_role_minecraft
```
